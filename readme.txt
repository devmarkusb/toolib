2. How to start
==========================================================================

In most cases you just need to include header files from subdir Toolib.
And, should it be necessary, just compile sources out of subdir src into
your project. The required ones should be easy too find according to the
names of the included headers.
For the time being there is no lib building procedure provided, because
there aren't any libs you would eventually have to link against.

Too find anything topic specific, just browse through the directory
structure and read header files.
